# Diplom_2
Автотесты для API веб-приложения "Stellar Burgers".

Проект содержит автоматизированные тесты для REST API сервиса «Stellar Burgers», написанные на Python с использованием фреймворка pytest, библиотек requests и faker, а также генератора отчетов Allure. 

Покрытые сценарии:
1. Создание пользователя:
- создать уникального пользователя;
- создать пользователя, который уже зарегистрирован;
- создать пользователя и не заполнить одно из обязательных полей.
2. Логин пользователя:
- вход под существующим пользователем;
- вход с неверным логином и паролем.
3. Создание заказа:
- с авторизацией;
- без авторизации;
- с ингредиентами;
- без ингредиентов;
- с неверным хешем ингредиентов.
